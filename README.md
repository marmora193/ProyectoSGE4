<h1>Objetivo del proyecto</h1>
<p>La empresa ficticia DP Oro necesita una aplicación interna que permita gestionar a sus clientes y registrar las ventas de oro realizadas en su local.
El objetivo del proyecto es integrar todos los contenidos vistos en la Unidad 4 mediante una aplicación modular en Python.

La aplicación debe incluir un menú interactivo, persistencia con SQLAlchemy, generación de datos con Faker, trazas con logging y gráficos con matplotlib.</p>
